# DeadTime — برنامه‌ریز شخصی

داشبورد فارسی مدیریت تکلیف‌ها و موعدهای تحویل، با رابط راست‌به‌چپ و طراحی واکنش‌گرا. یک سایت ایستا برای GitHub Pages؛ بدون نیاز به ساخت، حساب کاربری یا کلید API.

## امکانات

- افزودن، ویرایش، انجام دادن، بازگرداندن و حذف تکلیف‌ها با تأیید حذف.
- انتخاب درس از ML، NC، OS، AUTOMATA، PRESENTATION و WORK، یا ثبت نام دلخواه با Other؛ نام درس‌های قبلی هم حفظ می‌شود.
- نمایش تاریخ شمسی، اعداد فارسی و زمان باقی‌مانده به وقت محلی دستگاه.
- مرتب‌سازی به ترتیب موعد، جست‌وجوی عنوان، درس و یادداشت، و فیلتر وضعیت.
- تقویم ماهانهٔ شمسی با جابه‌جایی بین ماه‌ها، انتخاب روز و نشان‌گذاری روزهای دارای ددلاین، امتحان و کوییز.
- ثبت تاریخ و ساعت امتحان و کوییز، کارت نزدیک‌ترین ددلاین و نمایش درصد انجام‌شده‌ها.
- طراحی تیره با زمینهٔ مشکی، کارت‌های سرمه‌ای و تأکیدهای آبی.
- پیوست چند فایل، دریافت آن‌ها و حذف پیوست هنگام ویرایش؛ حداکثر ۲۵ مگابایت برای هر فایل.
- ذخیرهٔ تکلیف‌ها و فایل‌ها در IndexedDB مرورگر.
- دریافت و بازیابی پشتیبان JSON همراه با فایل‌ها، سازگار با پشتیبان‌های قبلی Due North.
- میان‌بر N برای تکلیف جدید و / برای جست‌وجو؛ غیرفعال هنگام تایپ یا باز بودن پنجره‌ها.
- قلم فارسی وزیرمتن به صورت محلی، همراه با مجوز OFL در پوشهٔ assets.

## اجرای محلی

```sh
node server.cjs
```

نشانی `http://localhost:4176` را باز کنید. Node فقط برای پیش‌نمایش محلی لازم است؛ سایت منتشرشده مستقیماً در مرورگر اجرا می‌شود.

## انتشار

مخزن: https://github.com/thisiscodecode/thisisiscodecode.github.io

گردش‌کار `.github/workflows/pages.yml` با هر push به شاخهٔ `main` اجرا می‌شود. در تنظیمات مخزن، بخش Pages، منبع انتشار را روی GitHub Actions قرار دهید. پس از استقرار موفق، نشانی سایت در خروجی همان گردش‌کار نمایش داده می‌شود.

می‌توانید به‌جای Actions از انتشار شاخهٔ `main` و پوشهٔ ریشه استفاده کنید. فایل `.nojekyll` و همهٔ دارایی‌ها در ریشه قرار دارند. نام مخزن با نام حساب متفاوت است؛ نشانی پیش‌فرض این پروژه `https://thisiscodecode.github.io/thisisiscodecode.github.io/` است.

## محل نگهداری اطلاعات

اطلاعات فقط در مرورگر و دستگاه فعلی، برای نشانی همین سایت ذخیره می‌شوند؛ به گیت‌هاب فرستاده نمی‌شوند و بین دستگاه‌ها همگام نیستند. برای انتقال از localhost به سایت منتشرشده یا مرورگری دیگر، ابتدا پشتیبان دریافت و در مقصد بازیابی کنید. پاک کردن داده‌های سایت یا بستن مرورگر خصوصی ممکن است اطلاعات را حذف کند.

بازیابی، رکوردهای جدید را به موارد موجود اضافه می‌کند؛ موارد قبلی حذف نمی‌شوند. بازیابی دوبارهٔ یک فایل، موارد تکراری می‌سازد. حداکثر اندازهٔ فایل پشتیبان برای بازیابی ۲۰۰ مگابایت است و دریافت پشتیبان حدود ۱۴۰ مگابایت پیوست خام را پشتیبانی می‌کند. فایل‌های بزرگ‌تر را جداگانه دریافت کنید.

تاریخ ورودی و تقویم هر دو شمسی هستند. تاریخ را با قالب ۱۴۰۵/۰۸/۰۱ بنویسید یا از تقویم کنار فیلد انتخاب کنید؛ اعداد فارسی، عربی و انگلیسی پذیرفته می‌شوند. ساعت جداگانه و بر اساس منطقهٔ زمانی دستگاه ثبت می‌شود. انجام‌شده علامت زدن یک تکلیف، به معنی ارسال آن به دانشگاه نیست.

## بررسی

```sh
node --test tests/app.test.cjs
```

آزمون‌ها تبدیل تاریخ، شمارش معکوس فارسی، نگهداری پیوست‌ها در پشتیبان و پذیرش پشتیبان‌های قبلی را بررسی می‌کنند.
